What this benchmark measures

Modern IR Bench compares retrieval methods on the same corpus, queries, and binary relevance judgments. Higher scores are better. The leaderboard reports retrieval quality only; it does not compare latency or throughput.

Query breakdowns regroup the existing per-query metrics. Relevant-document breakdowns report Target Recall over documents in the selected group, using the already published Top-10 rankings without rerunning retrieval.

Reproduction

Python code is the source of truth. The code icon beside each Solution opens its definition at the exact Git commit used for the published result. 

git checkout <source_commit>
uv sync
uv run python -m benchmarks.modern_ir_v2_1

Publication

This Space is read-only. New Tasks, Datasets, Solutions, and experiments are reviewed through GitHub pull requests and run in the maintained environment. The benchmark data are published as a Hugging Face Dataset.

Result model

A Task defines the evaluation protocol and its metrics. A Dataset is a versioned data release adapted to that protocol. One Task can use multiple Datasets, and the same source data can be adapted for different Tasks.

The underlying dimensions are Solution × Task × Dataset × Metric × Version. Dataset releases are immutable. New tasks and datasets can use different metrics without forcing an artificial overall score.
