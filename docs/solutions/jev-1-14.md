# Voyage 4 Large → Jev 1.14

Voyage 4 Large retrieves the top 50 candidate documents from shared 768-token chunks. Jev 1.14 receives those candidates as 50 separate relevance questions in one OpenRouter Decisions request. Each question contains one complete candidate document, while the query is shared state.

Documents are ordered by their individual relevance probabilities. Equal probabilities retain the first-stage Voyage order. The published result records the exact dataset revision, source commit, model identifier, and aggregate API usage; request caches remain local and are not part of the release.

Model: `typesafe/jev-1.14`  
Protocol: 50 isolated document questions per request  
Candidate depth: 50  
Second-stage input: complete document text
