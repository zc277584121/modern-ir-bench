# Modern IR Bench v2.2 historical ranking evidence

This directory contains the reviewed Top-10 document rankings used for the
current v2.2 leaderboard. It is a result artifact, not a Dataset and not an
executable Solution.

The rankings were originally generated by the private data-factory workflow:

- BM25 full/chunk, Voyage full/chunk, and Qwen chunk came from the candidate
  retrieval pipeline.
- BGE-M3 dense and learned-sparse chunk rankings came from the independent
  relevance-pool expansion retrieval.
- v2.2 renamed the Query field `task` to `query_intent`; retrieval was not
  rerun after v2.1.

The original run predates the public executable Solution catalog and was not
tied to a public Git commit. The Space therefore labels these rows as
`historical-artifact`. It recomputes all metrics from the immutable rankings
and pinned Dataset revision, but does not claim that replaying the artifact is
model inference.

Maintained executable definitions for all seven Solutions now live in
[`benchmarks/modern_ir_solutions/`](../../benchmarks/modern_ir_solutions/).
A future live run can replace this artifact while preserving the same Task and
Space schema.

## Files

- `rankings.jsonl.gz`: one `{query_id, solution_id, ranked_doc_ids}` row per
  Query × Solution pair. It intentionally contains no duplicated metric values
  or synthetic retrieval scores.
- `manifest.json`: Dataset revision, artifact type, migration note, inventory,
  and checksum.
